# Publisher-Only Offline License Issuance

The single-device edition can use offline signed licenses without a central
service or payment provider. The operator tool in scripts/issue_local_license.py
is outside the installed customer wheel. No production issuer key or customer
license has been generated by implementation checks; they use temporary test keys.

## Establish Publisher Trust

Run key generation deliberately in a protected publisher-owned directory outside
the repository, customer workspaces, public folders and synchronized/shared storage:

```powershell
python scripts/issue_local_license.py generate-key --private-key C:/QA-Issuer/private/issuer.key --key-id publisher-1 --public-keys C:/QA-Issuer/public/publisher-public-keys.json
```

Create those parent directories first. On Windows, restrict the private directory
with owner-only NTFS permissions; POSIX file creation uses mode 0600. The private
key is raw, unencrypted signing material. Back it up privately and never send it
to customers, chat, GitHub or the demo. Distribute only the public-key JSON file
through your chosen trusted customer delivery process. The tool refuses repository
paths, redirected paths, hard-linked private keys and existing output files.
No customer runtime can add issuer trust through a license document.

## Issue a Customer License

Use separate lowercase UUID hex strings for customer and license IDs. Set an
exclusive Unix expiry timestamp; project limits are optional (omission means
unlimited projects), while concurrent executions remain bounded from one to four:

```powershell
python scripts/issue_local_license.py issue --private-key C:/QA-Issuer/private/issuer.key --key-id publisher-1 --customer-id CUSTOMER_UUID_HEX --license-id LICENSE_UUID_HEX --expires-at EXPIRY_UNIX_SECONDS --max-projects 20 --max-concurrent-runs 2 --output C:/QA-Issuer/licenses/customer-license.json
```

Replace the uppercase placeholders before running. Deliver the signed document to
the customer for local import. It contains IDs/validity/entitlements only, no site
URLs, API/database settings, passwords or results. The tool sends no network
requests and prints no private key or signed payload. Existing files are never
overwritten. The private key must remain available only to the publisher.

This is license issuance, not billing, user registration or automatic revocation.
Offline customers can control their files and clock; enforcement is not claimed
tamper-proof. Rotating/revoking publisher trust requires a separate deliberate
customer configuration/distribution decision. No central account/backend is active.
